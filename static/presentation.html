Slide 2 • Introduction & Project Overview

Introduction to Recommender Systems

The algorithmic backbone of personalized digital media and content discovery

Definition & Essence

What is a Recommender System?

Information filtering algorithms that predict user ratings, preferences, and affinities for unrated items.

  • Personalized Discovery: Transforms vast libraries into tailored candidate sets matching individual taste profiles.
  • Industry Driver: Powers >80% of watched content on Netflix and >70% of YouTube video streams.
Motivation & Relevance

Why Recommenders Matter

Overcomes the modern "Paradox of Choice" where users face thousands of titles and experience decision paralysis.

  • Surfacing the Long Tail: Recommends hidden gems and niche titles beyond standard blockbusters.
  • Business Value: Enhances user retention, average session duration, and catalog discoverability.
Multi-Paradigm Approach

Core Methodologies Implemented

  • Knowledge-Based: Heuristic genre, popularity, and rating filtering for cold-start visitors.
  • Collaborative KNN: Memory-based item & user similarity via Cosine distance.
  • Matrix Factorization (SVD): 50 latent taste dimensions resolving 93% matrix sparsity.
  • Deep Learning (DNN): User & item embedding layers with Softmax multiclass outputs.
Project Deliverables

Project Scope & Objectives

  • Benchmark Evaluation: Trained and benchmarked on MovieLens 100K (100K ratings, 943 users, 1.6K movies).
  • Unified Web Application: Modern real-time UI with instant model comparisons and fuzzy search.
  • Interactive CLI: Standalone terminal command-line tool for live algorithmic testing.
Slide 3 • Problem Statement

Challenges in Movie Recommendations

Why naive recommendations fail in modern entertainment platforms

  • Information Overload: Users struggle to pick from thousands of available movie choices.
  • The Cold-Start Dilemma: Brand-new users have zero rating history, breaking pure collaborative filtering.
  • Extreme Data Sparsity: Over 93% of user-movie ratings are empty (unobserved).
  • Popularity Bias (The Long Tail): Systems often favor blockbusters, neglecting niche, high-satisfaction movies in the long tail.
Slide 4 • Dataset Overview

The MovieLens 100K Dataset

Industry benchmark dataset from GroupLens Research Project

  • Dataset Scale: 100,000 ratings (1 to 5 stars) from 943 users on 1,682 movies.
  • Quality Requirement: Every single user has rated at least 20 movies.
  • Metadata: 19 genre tags (Action, Sci-Fi, Drama, etc.), titles, release dates, and user demographic data.
  • Rating Distribution: Most users award 4-star ratings, followed by 3-star and 5-star ratings.
Slide 5 • Recommendation Concepts

Content-Based vs. Collaborative Filtering

Two foundational pillars of modern recommendation engines

  • Content-Based Filtering: Matches discrete item characteristics (genres, keywords, directors) to recommended titles.
  • Collaborative Filtering: Uses collective community behavior. Assumes users who agreed in the past will agree in the future.
  • Item-Based: Calculates similarity between items based on user rating patterns.
  • User-Based: Clusters like-minded users into neighborhoods to share personalized suggestions.
Slide 6 • Models 1 & 2

Knowledge-Based & K-Nearest Neighbors (KNN)

Instant cold-start resolution and memory-based collaborative filtering

  • Knowledge-Based Filtering: Ranks top-rated popular movies by genre. Completely solves the Cold-Start challenge for anonymous visitors.
  • KNN Item-Based Recommender: Builds a sparse matrix and uses Cosine Distance to find closest companion films.
  • KNN User-Based Recommender: Finds top $K$ peer users and weights candidate movies by inverse peer distance.
  • Dynamic Movie Suggestor: Substring & typo-tolerant matching allows users to find films without exact title spellings.
Slide 7 • Models 3 & 4

SVD Matrix Factorization & Deep Neural Networks

Latent factor discovery and non-linear deep learning

  • Singular Value Decomposition (SVD): Factors utility matrix $A$ into $U \Sigma V^T$ with 50 latent dimensions, uncovering underlying movie themes and user preferences.
  • Overcoming Sparsity: Reconstructs missing matrix values to predict unobserved ratings across the entire catalog.
  • Softmax Deep Neural Network (DNN): Uses learned user & item Embedding layers + Dense layers with Dropout.
  • Softmax Classification: Predicts probability distribution across rating categories for unseen movies.
Slide 8 • Application & Results

Interactive Dashboard & Key Takeaways

Project evaluation, summary of findings, and production architecture

  • Real-Time Web Application: Complete UI with 6 interactive tabs, autocomplete search, and instant model inference in <0.5s.
  • Hybrid Superiority: Knowledge-based handles new users, KNN provides immediate similarity, SVD solves sparsity, and DNN captures non-linear relationships.
  • Addressing Long-Tail: Matrix factorization successfully uncovers high-quality, lesser-known movie recommendations.
  • Scalability: Sparse CSR matrices and SVD projection reduce memory footprint while maintaining high recommendation fidelity.
